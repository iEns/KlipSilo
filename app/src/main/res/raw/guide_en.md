
KlipSilo — User Guide

About the app

KlipSilo is a smart manager that automatically saves everything you copy, create or drag in — like a flexible, temporary staging area. Here you can quickly find, organize and reuse content. KlipSilo handles text, URLs, images, PDFs, files, QR codes, GPS positions and OCR extraction. Everything can be shared directly from KlipSilo or sent to another app for further processing.

The OCR function does not require internet access.

Saving clips in KlipSilo

From clipboard
Press "Save current clipboard" — what you copied is saved automatically.

Extra options
Press ➕ and choose:
Text clip — write freely in the editor
QR scanner — scan a QR code with the camera and the text is saved
Camera/OCR — take a picture and extract text

From other apps
When you share content from another app (Gallery, Files, browser etc.), select KlipSilo in the share menu. The file is saved automatically.

Your position
Press the position icon to save your GPS coordinates. If the app can find the address, it is shown automatically. Double-tap opens Google Maps and starts navigation back to the saved position.

⸻

Using a clip

Double-tap the icon in the top left corner to see all available options for that clip.

Text can be edited directly
Files are saved byte for byte — the content can be viewed, and text files can be converted to a text clip
Originals are never changed — conversions always create new copies

⸻
Editing text

Open a text clip and write directly in the field
Press ✔️ to save
Press ← to go back — you are warned if there are unsaved changes
Press 📄 to turn the text into a PDF
Press the file icon to save the text as a TXT file clip

Note!
Double-tap on a text clip in the list for a quick overview of tappable content:
Phone numbers → tap to call
URLs → tap to open in browser

⸻
Search

Type search terms to filter the list.

⸻
Deleting clips

Individually
Press 🗑️ on a clip — Undo appears for 4 seconds.

Multiple at once
Press the top 🗑️ — check the clips you want to delete — delete — confirm.

⸻
Favorites (pin)

Press 📌 to pin a clip at the top. Clips are always sorted with newest first — pinned clips are shown first. Press again to remove.

⸻
Printing text

When you send unformatted text directly to the printer, you have no control over margin, text size or line spacing. Instead, convert the text to a PDF before printing — a PDF locks in the paper size, margins, font size and line spacing, so the layout does not change.

⸻
Sharing

Press 📤 on a clip to share it to another app (email, message etc.).

⸻
OCR — extract text from image

From camera
➕ → Camera/OCR → take a picture. In poor lighting or close-up shots, use the phone's own camera app and save the image in KlipSilo afterwards.

From saved image
Double-tap on an image in the list → Optical reader.

After the image is taken/selected
Black frame with gray handles shows which area is analyzed
Drag a handle to change size, or use the center to move the frame
Save image — saves the original image as an image clip
Save text — runs OCR and saves the text in the editor

⸻
OCR — from PDF

Whole PDF
Double-tap on a PDF → PDF → Text. All pages are OCR'd and combined into one editable text clip with "--- Page X ---" between pages. Works on both scanned and text-based PDFs.

Current page
Open the PDF → press the OCR button (T icon) at the bottom. The page you are viewing is OCR'd into a new text clip.

⸻
PDF viewing

When you open a PDF, the page is shown magnified. Use ◀ ▶ at the bottom to flip between pages, and pinch to zoom. The OCR page button (T icon) is also available here.

⸻
Conversion

Image → PDF: Double-tap on an image → Image → PDF. Keeps the image's own aspect ratio (4:3, 3:2 etc.).
PDF → Image: Double-tap on a PDF → PDF → Image. One image per page.
Text → PDF: In the editor → 📄. A4, 2 cm margin, 14 pt font, 1.4 line spacing, automatic page breaks.
Text → TXT: In the editor → the file icon. Creates a TXT file clip.
File → Text: Double-tap on a file clip → File → Text. Text files (under 2 MB) become an editable text clip.
PDF → Text: Double-tap on a PDF → PDF → Text (OCR of the whole PDF).

A "Converting…" dialog is shown during all conversions.

⸻
Files

View the full content by opening the file — text files show all content and can be scrolled.
File → Text (double-tap) converts the content into an editable text clip.
Save to Downloads (double-tap) copies the file to the phone's Downloads folder.

⸻
Language

Press 🌐 to switch between Danish and English.

⸻
Tips

At 25 or more clips the app asks whether to delete the oldest.
Deleted clips can be undone within 4 seconds.
Images, PDFs and files are saved as separate local copies — the original is unaffected.
A clip is never deleted automatically — not even after conversion.

Sharing multiple clips
1. Mark the desired clips in the top right corner.
2. Press Share on one of the selected clips.
Note: When you select the first clip, you can only add other clips with the same content type.

List sorting
Sorting is automatic by date and time (newest at top):
1. Selected clips are grouped at the top.
2. Pinned favorites are placed just below.
3. Other clips are placed at the bottom.
